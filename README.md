## 📌 Project Overview

The **Student Complaint Management System (SCMS)** is a web-based application developed to digitize the student complaint process.

Students can create an account, submit complaints, track their complaint status, view administrative feedback, and manage their account.

Administrators can securely access an administration panel to view submitted complaints, update complaint status, provide feedback, and manage complaints.

The system uses **HTML, CSS, JavaScript, PHP, and MySQL** to provide a complete frontend and backend workflow.

---

## ✨ Key Features

### 👨‍🎓 Student Panel

- 🔐 Student registration and login
- 📝 Submit complaints
- 🕵️ Anonymous complaint submission
- 📋 View submitted complaints
- 🔎 View individual complaint details
- 📊 Track complaint status
- 💬 View administrator feedback
- 🔑 Change account password
- ↩️ Withdraw submitted complaints
- 🚪 Student logout

### 🛡️ Administrator Panel

- 🔐 Secure administrator login
- 🔒 PHP session-based authentication
- 📊 Administrator dashboard
- 📋 View all complaints
- 🔎 View individual complaint details
- 🔄 Update complaint status
- 💬 Provide feedback to students
- 🗑️ Delete complaints
- 🚪 Administrator logout
